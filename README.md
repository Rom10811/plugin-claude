# daily-page

A Claude Code mod: a notebook-page side panel that sits beside the chat.

It shows a mascot that changes with your last action (editing, reading,
searching, running commands), a tally of edits/reads/searches/runs for the
current page, a to-do sticky note synced with the session's live todo list,
and a "pencil left" gauge based on the remaining context window and the
account's 5-hour/weekly usage windows.

## Install

```
/plugin install daily-page --marketplace Rom10811/plugin-claude
```

## Use

The panel opens automatically when a session starts. Reopen it any time
with `/daily-page`.
